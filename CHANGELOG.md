\# Changelog



All notable changes to DocumentConverter are documented in this file.



\## \[1.0.0] - 2026-11-02



\### Added

\- Initial public release of DocumentConverter.

\- Graphical user interface built with CustomTkinter.

\- Drag-and-drop file support.

\- Batch conversion of multiple documents.

\- Individual output format selection for each file.

\- Apply-to-all output format selection.

\- Conversion progress tracking.

\- Local conversion using a bundled LibreOffice runtime.

\- Windows installer created with Inno Setup.

\- Support for Word documents, spreadsheets, presentations, and HTML files.



\### Supported Formats

\- Word documents: DOCX, DOC, ODT, RTF, TXT

\- Spreadsheets: XLSX, XLS, ODS, CSV

\- Presentations: PPTX, PPT, ODP

\- Web documents: HTML, HTM

\- PDF output for supported document types.
