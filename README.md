\# DocumentConverter



\*\*A desktop application for converting documents between multiple file formats.\*\*



Developed by \*\*EightBit-Panda\*\*.



DocumentConverter is a Windows desktop application designed to make document conversion simple and convenient. It provides a graphical interface with drag-and-drop support and uses a locally bundled LibreOffice conversion engine.



All conversions are performed locally on your computer. No cloud service or subscription is required.



\## Features



\- Simple graphical user interface.

\- Drag-and-drop file support.

\- Batch conversion of multiple documents.

\- Individual output format selection for each file.

\- Apply one output format to all compatible selected files.

\- Conversion progress tracking.

\- Local document processing.

\- Bundled conversion engine.

\- No internet connection required for document conversion.



\## Supported Formats



\### Word Documents



Supported input formats:



\- DOCX

\- DOC

\- ODT

\- RTF

\- TXT



Available output formats:



\- PDF

\- DOCX

\- ODT

\- RTF

\- TXT

\- HTML



\### Spreadsheets



Supported input formats:



\- XLSX

\- XLS

\- ODS

\- CSV



Available output formats:



\- PDF

\- XLSX

\- ODS

\- CSV

\- HTML



\### Presentations



Supported input formats:



\- PPTX

\- PPT

\- ODP



Available output formats:



\- PDF

\- PPTX

\- ODP



\### Web Documents



Supported input formats:



\- HTML

\- HTM



Available output formats:



\- PDF

\- HTML



\*\*Note:\*\* PDF files can be added to the application, but further PDF conversion is not supported in version 1.0.0.



\## Installation



1\. Download the latest DocumentConverter installer from the GitHub Releases page.

2\. Run `DocumentConverter\_Setup.exe`.

3\. Follow the installation instructions.

4\. Launch DocumentConverter from the Start Menu or desktop shortcut.



The installer includes the required application files and conversion engine.



No separate Python or LibreOffice installation is required.



\## How to Use



1\. Start DocumentConverter.

2\. Add files using the file selection dialog or drag and drop them into the application.

3\. Select the desired output format for each file.

4\. Optionally, use the Apply-to-all function to select a common output format for compatible files.

5\. Start the conversion.

6\. Find the converted documents in the output folder.



\## Technology



DocumentConverter is built using:



\- Python

\- CustomTkinter

\- tkinterdnd2

\- LibreOffice



LibreOffice is bundled as the local document conversion engine.



\## Privacy



DocumentConverter processes documents locally.



Documents are not uploaded to an external conversion service as part of the application's conversion process.



\## System Requirements



\- Windows 10 or Windows 11.

\- 64-bit Windows system.

\- Sufficient disk space for installation and converted documents.
